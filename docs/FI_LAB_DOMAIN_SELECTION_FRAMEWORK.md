# FI-Lab domain eligibility and provenance

The retained common-core FI-Lab contains 12 laboratory domains:

creatinine, sodium, potassium, chloride, bicarbonate, glucose, haemoglobin, white blood cell count, platelet count, calcium, INR and magnesium.

The archived workflow supports the following properties of the final common core:

1. each retained domain is representable in MIMIC-IV, eICU-CRD and SICdb;
2. source measurements can be harmonised to a common analysis unit;
3. an interpretable abnormality/reference rule is available;
4. the same 12-domain definition is fixed across the cross-database primary analyses;
5. no retained domain is added or removed according to its observed mortality association;
6. FI-Lab is calculated only when at least 9 of the 12 retained domains are available.

The available archive does **not** preserve an exhaustive enumerated list of every laboratory domain considered before the 12-domain common core was finalised. The repository therefore does not reconstruct unrecorded excluded candidates.
