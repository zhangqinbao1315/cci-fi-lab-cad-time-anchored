# Data access and restrictions

This repository contains no patient-level data.

The manuscript uses controlled-access critical-care resources. Patient-level data must be obtained from the original custodians under the applicable access conditions:

- MIMIC-IV v3.1: PhysioNet credentialing, required human-subjects training and applicable data-use agreement.
- eICU-CRD v2.0: PhysioNet credentialing, required human-subjects training and applicable data-use agreement.
- SICdb v1.0.8: access under the database contributor's conditions, including study-level review/approval where applicable.

Derived patient-level CSV/RDS files used by the final analysis are also not redistributed because they remain patient-level derivatives of controlled-access source data.

The `verification/` directory contains only aggregate numerical outputs.
